# Revised paper draft: hidden-group bias with few demographic labels

**Beyond Demographic-Free Auditing: Measuring and Mitigating Hidden-Group Bias with Few Labels**
Chirag Joshi, Soumya Shradha, Tanishk Gangwar, Vivansh Garg and Yagya Salwan, Manipal University Jaipur.

This is the team's current paper, which follows on from the V6 candidate feature auditor in the rest of this
repository. The working copy lives on Overleaf. This folder keeps the reviewed revision for reference. It is an
unsubmitted draft.

| File | What it is |
|---|---|
| `main.tex` | IEEEtran conference source, a single file. Compile it with `pdflatex main.tex` twice. |
| `main.pdf` | The compiled paper, exactly 6 pages. |
| `CHANGES.md` | What was revised, and how every number was checked against the study's raw results. |
